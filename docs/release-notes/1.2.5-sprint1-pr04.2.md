# Release 1.2.5 — Sprint 1 · PR 04.2

## Simplificação da experiência de Prospecção

### Telas alteradas
- `src/routes/_authenticated.prospecting.tsx` — gate por flag + papel.
- `src/routes/_authenticated.settings.tsx` — novo card "Provedores de Dados"
  para Admin / SuperAdmin.
- Novo componente `src/components/simplified-new-prospection.tsx`.

### Navegação anterior
`Prospecção` mostrava cards por fonte técnica (Casa dos Dados, Google Maps,
LinkedIn Empresas, LinkedIn Pessoas, Instagram Empresas, Sites Corporativos,
API Própria, Webhook, Planilha CSV, Planilha XLSX) e uma aba
"Prospecção Inteligente — Beta" separada. Aba `Integrações` era visível a
todos os papéis.

### Nova navegação (flags ON)
```
Prospecção
├─ Nova Prospecção     ← Produto + ICP + região + segmento + meta
├─ Importar Base       ← CSV + XLSX unificados (/import)
├─ Histórico
└─ Integrações*        ← * apenas Admin / SuperAdmin
```
O vendedor não escolhe mais a fonte. O motor decide o discovery
(Casa dos Dados por padrão) e o Smart Flow decide o enriquecimento via
Provider Registry. Nenhum nome de provedor, API Key, URL técnica ou actor
do Apify é exposto ao vendedor.

### Permissões
- **SuperAdmin**: todas as integrações e configurações técnicas.
- **Admin da organização**: aba "Integrações" na Prospecção e card
  "Provedores de Dados" em Configurações.
- **Vendedor / SDR**: apenas Nova Prospecção, Importar Base e Histórico.

### Compatibilidade e Feature Flags
- Gate: `jcs_data_engine_enabled && smart_flow_ui_enabled`.
- Qualquer flag OFF → tela legada é renderizada exatamente como antes
  (cards de fontes, aba Integrações visível a todos). Zero mudança
  comportamental para clientes que ainda não migraram.
- Nenhuma rota removida, nenhum componente apagado, nenhum export
  renomeado. `SmartProspectPanel`, `NewSearch`, `Integrations` e
  `listSources` permanecem no bundle.

### Testes
- `bunx tsgo --noEmit` verde.
- Suíte existente do orquestrador e do Smart Flow (`validate.test.ts`,
  42+ testes) mantida sem alterações.
- Nenhuma API real é chamada pelos testes.

### Riscos
- Vendedor pode estranhar a ausência das opções de fonte. **Mitigação:**
  Nova Prospecção mostra o ICP e a compatibilidade dos filtros com
  destaque; Importar Base fica em aba dedicada.
- Casa dos Dados usada como discovery padrão pode não trazer resultados
  em nichos específicos. **Mitigação:** Admin ativa/desativa provedores
  em Configurações → Provedores de Dados; roadmap permite alternar o
  discovery padrão sem tocar na UI do vendedor.

### Rollback
Basta setar `smart_flow_ui_enabled = false` em `app_settings` — a tela
legada volta imediatamente. Nenhuma migração de banco foi feita nesta
entrega.
