# Release 1.3.7 — Centro de Diagnóstico (SuperAdmin)

## Objetivo
Painel interno somente-leitura para SuperAdmin identificar problemas do sistema em menos de 2 minutos, sem abrir banco, logs ou Supabase.

## Arquivos criados
- `src/lib/diagnostics.functions.ts` — server functions `getDiagnostics` e `runSelfCheck` (gate SuperAdmin, RLS respeitada).
- `src/routes/_authenticated.diagnostics.tsx` — página `/diagnostics` com 15 cards.
- `docs/release-notes/1.3.7-diagnostic-center.md` — este arquivo.

## Arquivos alterados
- `src/components/app-shell.tsx` — item de menu **Diagnóstico** (ícone `Activity`) visível apenas para `superadminOnly`.

## Cards implementados
1. Identificação (usuário, papéis, organização, release, ambiente)
2. Feature Flags (6 flags, com copiar)
3. Fluxo da Prospecção (smart vs legado + motivo)
4. Orchestrator (status, execuções, tempo médio, fila, retry, fallback, cancelados)
5. Providers (tabela completa)
6. Capabilities (primário + fallback)
7. Credenciais — mascaradas (`********XYZ`) dentro do card Providers
8. Health do sistema (Banco/Storage/Edge/Cron)
9. Integrações (Agenda, Email, WhatsApp, Orbit, Conta Azul)
10. Últimos erros (sem stack trace)
11. Log da última prospecção
12. Estatísticas (hoje/semana/mês/tempo/fallbacks/retries/leads/produtos/ICPs)
13. Botão **Executar diagnóstico** — self-check (Flags, Banco, Providers, Credenciais, Orchestrator)
14. Checklist (Banco, Providers ativos, Provider padrão, ICP, Produtos, Cadências, Leads, Agenda, Smart Flow)
15. Exportar JSON e TXT (client-side)

## Segurança
- Server functions gated por role `superadmin` (403 para demais).
- API keys, bearers, tokens e secrets **nunca** retornam ao cliente — apenas hint mascarado com últimos 3 caracteres.
- Stack traces omitidos.

## Permissões
- Somente `superadmin`. Admin/Gerente/Vendedor não veem o item de menu nem a rota (server function retorna `forbidden`).

## Compatibilidade / Rollback
- Nenhuma migration.
- Nenhum fluxo existente foi alterado (ICP, Smart Flow, Leads, CRM, WhatsApp, Cadências, Agenda, Email, Providers).
- Rollback: remover os 2 arquivos criados, reverter o menu em `app-shell.tsx`.

## Testes manuais
- Login como SuperAdmin → menu **Diagnóstico** aparece → página renderiza 15 cards.
- Login como Admin/Gerente/Vendedor → item ausente; acesso direto à rota retorna erro `forbidden`.
- Botão **Executar diagnóstico** retorna nível `ok/warn/error` com 4-5 verificações.
- Exportar JSON/TXT baixa arquivo com timestamp.

## Compatibilidade
Nenhuma regressão esperada — release aditiva.
