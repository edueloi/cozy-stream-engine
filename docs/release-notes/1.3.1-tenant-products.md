# Release 1.3.1 — Produtos por Organização

## Ajuste no campo Produto da Prospecção Inteligente

- Cada organização agora gerencia seus próprios produtos (criar, editar,
  duplicar, ativar/desativar, excluir, vincular ICP, definir padrão, ordenar)
  em `product_catalog`, isolados por RLS via `current_org_id()`.
- Dropdown de Produto na Nova Prospecção lista **apenas produtos ativos** da
  organização autenticada. Produtos inativos ficam ocultos para o vendedor.
- Nova opção **"+ Criar novo produto"** no dropdown abre um diálogo rápido
  (nome, descrição opcional, ICP opcional, status ativo). Após salvar, o
  produto é selecionado automaticamente e o ICP vinculado é preenchido.
- Removido o trigger `organizations_seed_product_catalog`. Novas
  organizações começam com catálogo vazio — os produtos padrão
  (Gestão de TI, Firewall, Backup, Microsoft 365, LGPD, SOC) permanecem
  apenas na organização JCS que já os possui, como exemplos.
- Segmento e CNAE não foram alterados. ICP, Leads, Cadências, Agentes,
  WhatsApp, Agenda, E-mail, Prospecção legada e integrações permanecem
  intactos.

### Testes
`src/lib/__tests__/products-filter.test.ts` (4/4 verdes):
- produto de uma organização não vaza para outra;
- produto recém-criado aparece imediatamente na lista;
- produto desativado não aparece para o vendedor;
- fluxo existente permanece compatível (status ausente = ativo).
