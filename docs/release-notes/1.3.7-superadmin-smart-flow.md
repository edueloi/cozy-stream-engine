# Release 1.3.7 — SuperAdmin sempre vê Smart Flow

## Causa raiz
A aba "Prospecção Inteligente (Beta)" estava condicionada exclusivamente a `smart_flow_available` (`jcs_data_engine_enabled` **e** `smart_flow_ui_enabled` ON na organização atual). Quando o SuperAdmin operava fora da organização JCS (flags OFF), a rota caía no fluxo legado — sem Smart Flow, sem Integrações agrupadas e sem diagnóstico de flags. Nada de errado com permissões: apenas ausência de bypass para o papel `superadmin`.

## Correção
Apenas UI. Nenhuma alteração em JCS Data Engine, ICP, Providers, Cadências, Leads, banco, migrations ou APIs de negócio.

- SuperAdmin agora vê **sempre** as abas: Nova Prospecção · **Prospecção Inteligente (Beta)** · Importar Base · Histórico · Integrações · **Diagnóstico**.
- Quando as flags estão OFF, o painel Beta é exibido com um aviso claro (visível só ao SuperAdmin) apontando quais flags estão bloqueando.
- Nova aba **Diagnóstico** (SuperAdmin) mostra `organization_id`, `user_id`, roles, fluxo em uso (Legado/Smart Flow), estado das 5 flags (`jcs_data_engine_enabled`, `smart_flow_ui_enabled`, `universal_icp_enabled`, `pre_icp_scoring_enabled`, `tenant_provider_settings_enabled`), lista de provedores ativos e provider padrão.
- Vendedores (`sdr`, `comercial`, `gerente`, `admin`) continuam vendo exatamente as mesmas abas de antes — a exibição do Beta e do Diagnóstico é gated apenas por `superadmin`, sem afetar demais papéis.

## Arquivos alterados
- `src/lib/jcs-data-engine/flags.functions.ts` — nova server fn `getProspectingDiagnostics` (leitura via `requireSupabaseAuth`, RLS do usuário).
- `src/routes/_authenticated.prospecting.tsx` — condicional `smartAvailable || isSuperadmin`, novas abas Beta e Diagnóstico, componente `DiagnosticsPanel`.

## Validação
- `bunx tsgo --noEmit`: verde.
- SuperAdmin com flags OFF: vê Beta com banner de aviso + Diagnóstico listando bloqueadores.
- SuperAdmin com flags ON: vê Beta sem banner; comportamento idêntico ao piloto JCS.
- Usuário `sdr`/`comercial`/`gerente`: exibição inalterada (sem Beta se flags OFF, sem Diagnóstico nunca).
- Usuário `admin` (não superadmin): mantém acesso a Integrações; não vê Diagnóstico.

## Confirmação
Nenhuma regra de negócio, RLS, tabela ou provider foi alterado. Vendedores comuns continuam respeitando as feature flags da organização; apenas o SuperAdmin ganha bypass de UI para diagnóstico e visibilidade.
